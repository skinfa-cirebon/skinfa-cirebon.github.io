Apa itu Flutter?

Flutter adalah UI toolkit dari Google untuk membangun aplikasi yang dikompilasi secara native untuk mobile, web, dan desktop hanya dari satu codebase. Cepat, Ekspresif, dan Native.

Pertemuan 2: Layouting

Semua yang Anda lihat di layar Flutter adalah Widget. Mari kita susun mereka.

import 'package:flutter/material.dart';

void main() => runApp(MyApp());

class MyApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(title: Text('Layouting')),
        body: Center(
          child: Container(
            color: Colors.blue[100],
            padding: EdgeInsets.all(20),
            child: Text('Hello RPL'),
          ),
        ),
      ),
    );
  }
}
