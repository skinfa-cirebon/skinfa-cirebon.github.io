1. Algoritma

a. Naratif

Penyajian algoritma dalam bahasa sehari-hari. Cocok untuk masalah sederhana yang tidak memerlukan simbol teknis.

b. Pseudocode

Kode semu yang mendekati bahasa pemrograman asli namun tetap mudah dibaca manusia.

IF nilai > 75 THEN
    PRINT "Lulus"
ELSE
    PRINT "Remedial"

c. Flowchart

Representasi grafis dari langkah-langkah algoritma menggunakan simbol standar (Oval, Jajar Genjang, Persegi Panjang, Belah Ketupat).

Visualisasi alur proses dari Start hingga Finish.

2. Pemrograman

a. Tipe Data

  • Integer: Bilangan bulat.
  • Float/Double: Bilangan desimal.
  • String: Kumpulan karakter/teks.
  • Boolean: True atau False.

e. Percabangan

Struktur kendali untuk memilih eksekusi kode berdasarkan kondisi tertentu (If-Else, Switch Case).

Satu Kondisi

if (lapar) { makan(); }

Dua Kondisi

if (hujan) { bawa_payung; } else { jalan_kaki; }

f. Perulangan (Looping)

Digunakan untuk menjalankan blok kode yang sama berkali-kali secara efisien. Contoh: For, While, dan Do-While.
